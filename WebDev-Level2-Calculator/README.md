# Vanilla JavaScript Calculator

A fully functional, browser-based calculator built using HTML5, CSS3, and Vanilla JavaScript. This project was created as part of a Web Development Level 2 challenge.

## 🚀 Features

- **Basic Arithmetic**: Supports addition, subtraction, multiplication, and division.
- **Operator Chaining**: Allows sequential operations (e.g., `5 + 3 × 2`) without needing to press equals between every step.
- **User-Friendly Interface**:
    - Responsive numeric keypad.
    - Clear (AC) and Delete (DEL) functionality.
    - Decimal point support.
- **Error Handling**: Prevents division by zero by displaying an error message.
- **Modern Layout**: Built with **CSS Grid** for a clean, aligned button interface.
- **Clean Code**: Implemented using event listeners and a class-based state management system, avoiding the use of `eval()`.

## 🛠️ Tech Stack

- **HTML5**: Structure and semantics.
- **CSS3**: Styling and Grid layout.
- **JavaScript (Vanilla)**: Application logic and DOM manipulation.

## 📂 Project Structure

- `index.html`: The main HTML file containing the calculator structure.
- `style.css`: Styles for the calculator layout and design.
- `script.js`: Core logic for arithmetic operations and UI updates.
- `instructions.txt`: The original requirements for the project.

## 📖 How to Run

1. Clone or download the `WebDev-Level2-Calculator` folder.
2. Open `index.html` in any modern web browser.
