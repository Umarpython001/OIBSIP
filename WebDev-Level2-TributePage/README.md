# Tribute Page - Alan Turing

A visually engaging tribute page dedicated to Alan Turing, the pioneer of theoretical computer science and artificial intelligence. This project was created as part of a Web Development Level 2 challenge.

## 🚀 Features

- **Responsive Design**: The page adapts seamlessly to different screen sizes, from desktops to mobile devices.
- **Typography Focus**: Uses a combination of serif fonts for elegant headings and sans-serif fonts for readable body text.
- **Visual Sections**:
    - A dedicated header with a title and tagline.
    - An image section with a caption.
    - A detailed biography consisting of several informative paragraphs.
    - A distinctively styled quote block.
    - A timeline of key achievements implemented as interactive styled cards.
- **Aesthetic Styling**: Employs a professional color palette with alternating background colors to separate content sections.

## 🛠️ Tech Stack

- **HTML5**: Used for structured semantic layout.
- **CSS3**: Used for styling, custom properties (variables), and a responsive layout using media queries.
- **Google Fonts**: Integrated 'Playfair Display' and 'Roboto' for enhanced visual hierarchy.

## 📂 Project Structure

- `index.html`: The core HTML structure.
- `style.css`: All styling, including the responsive design logic.
- `instructions.txt`: The original requirements for the project.

## 📖 How to Run

1. Clone or download the `WebDev-Level2-TributePage` folder.
2. Open `index.html` in any modern web browser.
